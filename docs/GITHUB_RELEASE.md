# PSA Play {{VERSION}}

基于上游 DiPlay v0.2.17 与 DiPlay-CN 二次开发。应用名称 **PSA Play**，包名 `com.peugeotplay.cn`，可与官方版并存。覆盖安装上一版即可保留设置。

**测试范围：** 实车验证车辆为 **2025 款比亚迪汉 DM-i，车机 DiLink 5.0**。其他车型、其他车机系统不保证所有功能可用；请自行测试，或拉取源代码按本车修改。

**下载**

- APK：本 Release 附带的 `PeugeotPlay-cn-v{{VERSION}}.apk`
- 完整优化记录：[docs/CN_OPTIMIZATIONS.md](https://github.com/leonz973/PeugeotPlay-CN/blob/main/docs/CN_OPTIMIZATIONS.md)

**本版更新**

- 合并上游 v0.2.8 – v0.2.17 全部功能：Same LAN（已有 Wi-Fi）连接模式、设置页按驾驶目标分组、DiLink 3/4/5 支持、USB 充电电流选择、应用内更新检查、繁体中文界面、软件 Opus 编码器、自定义转向卡与仪表地图同步等。
- 保留 CN 版客户端网络（手机热点/局域网）模式与全部既有 CN 增强。

请安装在车机上，不要安装在 iPhone 上。车机必须允许安装 APK。有线连接需要 Android 9 及以上；无线支持客户端网络（手机热点/局域网）、车载热点，或 Wi-Fi Direct（需 Android 10 及以上）。
